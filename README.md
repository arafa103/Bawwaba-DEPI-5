# 📎 Project Name: Bawwaba (بوابة)

> **Minified College Information System**  
> *A capstone project developed under the Digital Egypt Pioneers Initiative (DEPI) — Version 5.*

---

## 📌 Project Overview
**Bawwaba** is a practical web application designed to consolidate core React and Node.js skills acquired during the DEPI program. The platform serves as a simplified college website featuring student profiles, degree transcripts, multi-term GPA calculations, visual grade trend charts, a visual drag-and-drop course schedule builder, department leaderboards, and administrative management views.

## 🎯 Project Vision
> **FOR** college students **WHO** need a clear, unified portal to track academic records and easily sign up for courses without schedule conflicts,  
> **BAWWABA IS A** lightweight, web-based College Portal  
> **THAT** provides instant multi-term GPA tracking, visual performance trends, and an interactive drag-and-drop schedule builder.  
> **UNLIKE** rigid, outdated portal interfaces that only display lecture/section times in static tables and provide only cumulative GPA,  
> **OUR PRODUCT** delivers a responsive, modular React & Node.js user experience designed for effortless grade visualization and conflict-free course selection.

---

## 📦 Project Scope

### 💻 Core Tech Stack & Architecture
* **Front-End:** React.js, Bootstrap / React Bootstrap / Chakra UI *(TBD)*
* **Back-End API:** Node.js, Express.js

### ⚙️ Included Key Features
1. **Student Profile & Transcript Engine:** Displays personal info, course degrees, numerical scores, letter grades, per-term GPAs, and cumulative GPA.
2. **Student Dashboard & Visualizer:** Displays term-by-term performance trend graphs and top-performing student lists per department.
3. **Drag-and-Drop Course Signing:** Interactive timetable grid allowing students to manually drag courses into lecture/section time slots with real-time credit-hour tracking.
4. **Admin Management Views:** Admin interface displaying student directories, course list updates, and total enrollment counters per course.
